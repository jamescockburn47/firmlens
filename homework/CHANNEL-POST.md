# Follow-on message for the residency channel

FirmLens is now running on Vercel and Neon, with the code and updated architecture diagram on GitHub.

**The homework is to use [firmlens.app](https://firmlens.app) and decide what would make it better.** Start with your own experience; use an agent afterwards to investigate what you noticed.

Two ways to take part:

- **Give feedback:** check accuracy, missing coverage, useful features and design. Post what you tried, what you noticed, and what you would keep or change — with a reason and a link or screenshot. [What to look for](https://github.com/jamescockburn47/firmlens#homework-start-here).
- **Optional: make one small improvement:** create a GitHub account and send me your username if you want contributor access. Use your agent to help make and test one change, then submit a pull request for me to review. [Step-by-step instructions](https://github.com/jamescockburn47/firmlens#optional-make-one-small-pr).

The README also explains [how the app works, with a diagram](https://github.com/jamescockburn47/firmlens#how-the-app-works), and [what to question about its AI](https://github.com/jamescockburn47/firmlens#what-to-question-about-the-ai).

The point is judgment and taste: notice something yourself, decide why it matters, and check whether the proposed change is actually better. Feedback is just as welcome as code. We will publicly credit contributors; tell me how you would like to be named.
