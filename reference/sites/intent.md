# FirmLens — law firms and AI

Help a visitor answer: which firms are using AI, what have they actually announced, and what changed since we last checked?

The residency questionnaire received ten responses. Organisations led with four; no final ballot winner was recorded. James chose the law-firm AI tracker. Six preferred a searchable table, six a plain design, six weekly updates, eight filters. Four selected AI change explanations. Navy is a design choice among tied palettes, not a vote winner.

First version: a public, source-backed tracker of official law-firm announcements about adoption, partnerships, products, policies and training. Keep publication date, firm, region, category, original URL, evidence and last-check time. Save source snapshots and AI outputs in a real database. AI summarises an announcement and explains observed source changes; code validates evidence and controls writes. A failed fetch is visible, not a fabricated update. An unchanged check is a useful result.

Demo: search a firm, inspect its announcement and supporting source, run an owner-authorised check, inspect the saved AI summary and check history, refresh the page and recover the same record. Rechecking must not create another announcement. A synthetic changed-page fixture may test the change mechanism, but must never appear as a real firm's announcement.

This initial collection is curated and incomplete. Sources contain firms' own claims. An announcement does not establish effective deployment or independent product quality. No legal advice, rankings or inferred confidential information.

Target: deployed first version within 35 minutes from the 14:31 UTC build start. Report actual elapsed time and unmet capabilities honestly. Use remaining time for UI/UX, evaluation and hardening.
